# Gesture Gallery

An interactive browser-based image gallery where users can upload images and move them around using gesture-inspired interactions.

The idea is simple: upload images, then interact with them more like objects on a canvas instead of items inside a static gallery.

## Why I built this

I built this as an AI-assisted coding experiment to move beyond static design screens and understand how interaction, motion, layout, and feedback actually behave in the browser.

As a Product Designer, I have mostly worked in Figma and product workflows, but I have been actively exploring how to get closer to implementation. This project was a small way to experiment with direct manipulation, image-based interaction, and browser prototyping through code.

The idea was simple, but the learning was real.

## What it explores

- Image upload interactions
- Gesture-inspired controls
- Drag-based movement
- Direct manipulation
- Visual layout experimentation
- Micro-interactions and user feedback
- AI-assisted prototyping
- Moving from design idea to working browser experience

## What I learned

This project helped me understand that even a simple gallery needs a lot of product/design decisions:

- How should an uploaded image appear on screen?
- How much instruction does the user need?
- What makes dragging feel natural?
- When does an interaction feel playful vs confusing?
- How should visual content behave when it is no longer locked inside a grid?
- What makes a browser interaction feel more tactile?

It also helped me get more comfortable using AI as a coding partner — not to replace design thinking, but to quickly test ideas and learn implementation patterns.
